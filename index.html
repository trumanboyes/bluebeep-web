[ INFO — SS5 SYSTEM ]

              

                
SS5 (CCITT Signaling System No. 5) used Multi-Frequency
                tones to route international calls. A 2600 Hz tone placed
                on an idle trunk caused switches to believe the line was
                on-hook, granting control to the caller.

                
BlueBEEP (1993–1995) was written in Pascal by
                Stefan Scheytt (alias "Onkel Dittmeyer").
                This web reimplementation is an independent tribute —
                no original code was reused. SS5 has since been fully
                replaced by digital signaling.

                
Original author: Stefan Scheytt
                ("Onkel Dittmeyer") — all credit for the concept and
                the original BlueBEEP program belongs to him.

                
⚠ This simulator generates tones for
                educational/historical purposes only. Modern telephone
                networks are not affected.

                
This web reimplementation is released
